**Instructions (please read carefully)**

1. All file names (program names and input/output file names) must use lowercase English letters.
2. The return type of the `main` function must be `int`, and its return value on normal termination must be 0.
3. Place submitted source files in the location specified by your local contest organizers.
4. Appeals concerning errors or problems caused by violations of the three rules above will not be accepted.
5. Unless otherwise stated, outputs are compared in full, ignoring trailing spaces on each line and trailing line breaks at the end of the file.
6. Submitted source files must not exceed 100 KB.
7. The stack memory limit is the same as the problem's memory limit.
8. The national judging machines use an Intel(R) Core(TM) i7-8700K CPU at 3.70 GHz and 32 GB of memory. The stated time limits refer to this configuration.
9. Additional sample files are provided in Linux format only.
10. Judging uses the latest announced NOI Linux environment, including its compiler versions.
