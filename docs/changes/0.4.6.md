# TaskWeave 0.4.6

2026-11-04。修复执行权限隔离与部分分解释，保留现有题库、批量导入规则和测试点身份。

## 执行与文件权限

- `Runner` 统一编译和运行入口；运行前只解析可信 PATH 中的可执行文件，按角色授权程序、运行时、输入和工作目录，不因选手程序的文件名为 `python` 等而将它视作可信运行时。
- Windows：每次运行独立 AppContainer；无外部运行时的单进程程序使用 LPAC，编译器／解释器采用兼容的 AppContainer。Job Object 约束子进程与资源，保留必要句柄，不继承宿主环境；临时授权在结束后撤销。可信运行时的只读 capability 可复用，目录查找权限不等于授权读取其中全部文件。
- Linux：bubblewrap 创建独立文件系统、PID、网络和 IPC 等命名空间；仅运行时和必要输入只读、明确工作目录可写。seccomp 拒绝网络与危险系统调用；保留 namespace init，避免用户程序作为 PID 1 时改变信号语义。资源统计排除已观察到的 bubblewrap 辅助进程 CPU。
- 编译拒绝工作区外依赖、私有缓存和测试数据头文件；编译结果检查链接后由宿主保存，Windows 可执行文件不会携带导致正常运行异常的低完整性标签。
- 解法与 interactor 分目录，生成结果必须是普通独立文件。AI 接受修改和文件接口校验实际路径，拒绝符号链接、junction、硬链接与根目录修改。
- Electron 保留 sandbox、关闭 Node 集成，校验真实 origin 而非字符串前缀，拒绝危险外部协议和不需要的权限。Linux 启动及成品测试不使用自动 `--no-sandbox` 回退。

## 部分分

- `checker.scoring` 支持 `fraction`、`points`、`percent`、`hydro`，信息面板可配置，变更 checker 时不沿用另一个文件的单位。
- 新评测记录分开保存绝对 `points` 和比例 `fraction`。捆绑组取最小实际分，按点组求和；共享测试点按自己的组满分换算，部分正确为 PC，前置组仍需完全通过。
- `_pc` 与数值 `quitp` 使用报告解析，无法解释的 `quitpi`、非数值和越界报告不再误判为通过。
- Hydro 自定义 Testlib 导入设置兼容模式，保留其条件百分比规则、逐点向下取整及非完全通过状态；计分协议能安全转换时为导出生成适配源码。
- 洛谷导出每个捆绑测试点使用组满分，提供独立子任务 min/sum 脚本和整题依赖脚本；再导入时同时核对元数据、脚本与实际配置，注释不能覆盖不同的计分语义。仍需要用户在洛谷配置脚本。
- Polygon 包写入支持的比例计分标记；无法设置的 API 模式、与本地不等价的比例依赖阻止转换。自定义本地 checker 未配置 Lemon 版本时不再静默改用默认比较器。

## 验证与限制

回归新增目录外访问、环境泄露、本机网络、输出链接、编译依赖、运行时伪装、导航协议、计分单位、脚本篡改及跨平台 checker 转换用例。Windows 全量测试、Linux 原生专项及全量 CI、前端构建、桌面成品冒烟和发行附件校验是发布门槛。

支持边界、Linux 依赖和未覆盖的运行时详见 [security.md](../security.md)。没有宣称可防御内核漏洞、提供完整磁盘配额或可直接作为公开在线评测服务。
