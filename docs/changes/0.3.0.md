# PolyForge 0.3.0 改动明细

基于 0.2.3，发布日期 2026-10-18。本轮新增 OI 文档、评测及比赛下发流程，所有工作区包统一为 0.3.0。

面向用户的说明见 [0.3.0 发布说明](../releases/0.3.0.md)，检查结果见 [发布检查记录](../releases/0.3.0-review.md)。上一版记录见 [0.2.3 发布说明](../releases/0.2.3.md)和[修复明细](0.2.3.md)。

## 题面编辑与格式转换

- 题面／题解可混写 Polygon TeX 与 Markdown；渲染时在内存中转换，原文件保持原样。支持标题、粗斜体、列表、表格、代码、链接和本地图片，并保留公式、TeX 命令、注释及 verbatim 内容。
- 增加引用框、删除线、分隔线；同步预览展示 Polygon 不支持的语法与位置，同步／Polygon package 使用兼容 TeX 并提示排版降级。独立 TeX 导出附带对应环境及宏包。
- 修复粗体内公式导出 Markdown 时产生大量 HTML，改用 Markdown 粗体包裹文字和公式；题面检查和自动修复保留合法 Markdown、代码空白及字面标记。
- 新增 shared/oi/defs.toml：文件／标准输入输出、数据范围、子任务、依赖、大样例和 grader 接口等 12 组中英文术语，接入预览、导出、AI、补全及悬停说明，不覆盖已有 CF 宏文件。

## OI 排版与比赛文件

- 内置 CNOI statement generator 的 Markdown 编译模块、Typst 模板、WASM、字体及依赖，固定上游版本；OI 预览与 PDF 使用同一份编译结果，运行时可离线生成。
- OI 提供 SVG 页面预览及 PDF、Markdown 导出；修改选项后自动更新，更新期间禁用旧文档导出，忽略过期渲染请求。Markdown 复用 CF 序列化与图片打包流程。
- 适配英文表格、日期、输入输出、章节和页码，保留【Description】等章节中括号；修复脚注标记与正文首行错位，保留多段脚注。适配代码独立于上游源码。
- 每场比赛拥有独立 files/，提供新建、上传、编辑、预览、下载和删除；文件页采用左侧文件、中间编辑器／预览、右侧比赛信息的三栏布局，保留保存冲突与未保存提醒。
- notes.tex 默认为空；非空时显示目录下的注意事项，可插入中英文 CNOI 模板。CF 的 PDF、HTML、Markdown、TeX 也包含注意事项。
- 可生成整场题面／题解快照并复制本地图片；每次生成新目录，不覆盖原题或旧快照。题面与题解分别只允许所有题目共有的非空语言，前后端均校验。
- 快照保存语言标记，旧快照从目录名识别语言；预览宏按文件语言展开，与下一份文档的生成语言独立。补齐比赛文件页的 KaTeX 样式，修复公式重影。
- 比赛 AI 可访问 files/，沿用审阅／接受／撤销流程，文件链接可打开比赛文件工作区。

## OI 评测与兼容性

- 新建题目可选传统题、I/O 交互题、grader 交互题；grader 与选手 C++ 源码共同编译，支持多源文件及头文件，贯穿生成答案、快速运行、批量评测和对拍。
- 支持子任务捆绑、按点计分、分数和依赖；修复依赖结果受定义顺序影响及依赖失败未传递，校验循环、重复归属和非法分值。
- grader 和 checker 的头文件变化使编译缓存失效，每份源码仍使用一个 exe 缓存位置；重命名 grader 文件／目录时同步更新配置，删除源文件后避免留下无效 TOML。
- grader 不支持 Polygon；小数分值、仅下发的大样例在同步前明确提示，并阻止不兼容操作。普通 checker 与独立 Lemon checker 分别配置。
- 既有项目继续兼容原 interactive 字段；OI 排版样式不要求把已有题目转换为另一种题目类型。

## LemonLime 与选手下发包

- 比赛可导出 LemonLime ZIP：JSON CDF v1.0 配置标题、时空限制、输入输出、checker、子任务和依赖；题目数据位于 data/题目英文名/，source/ 为空。支持传统题和 grader Communication 模式；任一题失败不输出残缺包。
- 内置独立的 Testlib for Lemons，使用 Lemon Special Judge 协议。导出前检查所有 checker 配置及编译，生成数据后用首个测试的标准答案验证评分文件及满分结果；附检查器源码、所需本地／共享头文件和许可证。
- 可从标准／本地 C++ checker 创建独立 Lemon 副本：替换 testlib 头文件及初始化调用，保留简单 quitp 的比例计分；不覆盖原文件，复杂计分接口提示手动处理。
- 样例可关闭“在题面中展示”，作为大样例下发；预览、PDF、Markdown、TeX 显示一致的编号和文件提示。
- down.zip 包含整场 OI statement.pdf 及所有样例，如 trip/trip1.in、trip/trip1.out。按原测试编号升序连续编号，保留题面样例覆盖及完整大文件，不包含私有测试、标程和 grader；打包前校验预览与源内容一致。
