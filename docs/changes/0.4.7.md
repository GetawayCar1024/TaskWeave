# TaskWeave 0.4.7

2026-11-06。本地 Polygon 整场导入，沿用既有题包转换与比赛发布流程。

- `/api/contest-packages/*` 支持 Polygon 与 LemonLime，候选附带格式、原题号和多语言标题；旧版不带格式的请求仍可识别。
- 按 `contest.xml` 顺序解析题目目录或内嵌 ZIP，或从多个 Polygon 目录推断一场比赛；拒绝路径越界、XML 外部实体、重复题号和超限解压。
- 复用 Polygon 单题转换，保留源文件名、题面、测试集、分数、检查器和原件；不建立 Polygon 在线绑定。转换边界不变。
- 全部选中项先检查名称、目标文件夹和配置，再写入；取消的题目和公共文件归入比赛原件，其他比赛的原件不混入当前比赛。
- 题目发布中的注册或测试扫描失败也会清理刚创建的目录，避免留下半成品。
- 新增 API、目录上传、内嵌 ZIP、大小写描述文件、多语言、同名不同文件夹、排除题目、失败回滚和原生比赛包往返测试；加入完整回归入口。
