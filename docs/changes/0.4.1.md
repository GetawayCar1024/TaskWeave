## 验证方法

文件系统与导入使用隔离目录的 API 回归；交互问题使用本地模拟 AI 流与浏览器复现；发布前执行完整回归、类型检查和成品验证。

交互复现命中了八个具体症状，修复后全部转绿：手动保存依赖、设置编辑器未落盘、旧 ID 标签、兼容 AI Tab、后台状态初始化、无条件滚到底部、评分元数据触发生成、接受修改后依赖文件监听。设置使用串行自动保存队列；AI 的编译／运行／批量评测与自测权限取自真实题目，不信任可编辑的沙箱配置。

格式依据见 [FPS 与 Lemon 原生比较研究](../research/fps-lemon-builtins.md)。FPS 为 UTF-8 XML，支持多题、样例、测试、图片与源程序；不能代表的评分、附件或评测器配置会明确提示。Lemon 内置模式为 0／1／3，本地 C++ 比较器对齐原生 EOF、分行、32 字节分块及 long double 规则，导出时直接配置 CDF。

Lemon 导入先检查 CDF 与实际 `data/` 清单，再发布题目：旧版二进制核对 Qt CRC-16、qCompress 和 QDataStream 边界；每份 CDF 使用自己的目录根和任务序号。子任务中的依赖哨兵与实际测试分别处理，共享数据和重复测试出现次数继续保留。原件置于 `other/lemonlime/`，导入说明另存为 `other/lemonlime-import.md`，避免与包内说明文件同名。

重导出回归进一步发现并修复了模式 5 被降为默认比较、二进制 SPJ 绕过未解决检查、报告覆盖原文件、大小写修复错误混入答案后缀替换的问题。FPS 名称顺序错位用真实导入回归锁定。缺失或不明确的引用不产生部分题目；只带二进制的有效 SPJ 题包可保留数据，但在明确选定本地比较方式前阻止不准确的评测包输出。

最终界面回归包含 13 项，已在生产前端及隔离本地 AI 服务上通过：设置／编辑器自动保存、旧名称、兼容 AI、后台指示、历史滚动、子任务编辑、AI 接受刷新、题库与比赛目录、目录导入、原生 Lemon 比较、Lemon 导入错误处理及未保存草稿保护。
