# TaskWeave 0.4.3

2026-11-01 发布，基于 0.4.2。面向用户的说明见 [0.4.3 发布说明](../releases/0.4.3.md)，上一版见 [0.4.2 改动明细](0.4.2.md)。

## 推送到 LemonServer

- 新增 `secrets.toml` 的 `[lemonserver] url / key`；设置页“LemonLime Server”可保存、清除密钥并测试连接（`POST /api/lemonserver/test`）。凭据可以是 API Key 或访问令牌（换取会话）。版本只显示 LemonServer 自身版本。
- 新的比赛批量操作 `lemon-push`（`ContestBatchRequest.lemonServer`）：连接服务器 → 检查同名比赛（须确认替换；正在评测或排队时拒绝）→ 可选保存原 `source/` 与 down.zip → 生成 down.zip → 按服务器系统导出 LemonLime 包 → `POST /api/import-contest` → 恢复选手程序、上传或恢复 down.zip、恢复比赛时间 → 服务器编译自定义检查器（`files/compile`，附带 Testlib for Lemons 头文件）。本地 ZIP 只用于上传，完成后删除。
- 同系统时服务器编译成功才替换 TaskWeave 预编译的检查器，失败沿用预编译版本并给出提示；可关闭服务器编译。跨系统时编译失败的题目标为失败并附编译输出。
- down.zip：`samples` 只打包样例；`pdf` 由浏览器按比赛的 OI 排版设置排版题面，服务端核对题面快照后与样例一起打包，内容在排版后改变时拒绝推送。
- 查询参数改为百分号编码（Qt 不把 `+` 当作空格），修复名字含空格的比赛被导入为错误名称。
- 推送窗口拆为独立组件：服务器状态卡片、比赛、选手下发包与测试集分区；OI 题面内容组装与排版逻辑抽到 `lib/oiDocument.ts`，与打印页 OI 预览共用。

## Linux

- 桌面构建先生成应用目录，再把 `taskweave` 换成启动脚本（真正的程序为 `taskweave-bin`，Electron fuse 仍写在其中），最后生成 AppImage 与 tar.gz。脚本在 `chrome-sandbox` 非 setuid root 且非特权用户命名空间受限时加 `--no-sandbox`。
- 系统字体：缺少 SimSun / SimHei / KaiTi 时加载已安装的 CJK 字体（Noto CJK、思源、文泉驿、AR PL、Droid、Fandol、霞鹜文楷等，搜索 `/usr/share/fonts`、`~/.local/share/fonts` 等目录）作为逐字回退；`GET /api/system-fonts` 返回 `fallbacks`。
- 文档补充 libfuse2、沙箱与中文字体说明。

## 测试

- 新增 `test-lemonserver.ts`（模拟 LemonServer：设置与凭据、推送与替换、跨系统和同系统编译、down.zip 与比赛时间、评测队列），扩充字体回退测试；全部 164 项在 Windows 与 Ubuntu 26.04 通过。
- 实测：Windows → Ubuntu LemonServer 0.1.2 / 0.1.3，Windows → Windows 0.1.3，Linux 桌面版界面流程（浏览器排版的 PDF 写入 down.zip），以及 0.1.3 保留预编译检查器的可执行权限。
