# TaskWeave 0.4.5

2026-11-03 发布。在 0.4.4 之后加入测试点批量删除与删除后的重新编号，改变导入时对缺失测试数据的处理，并适配 LemonServer 0.1.6。

## 删除测试点

- 新增 `DELETE /api/problems/:id/tests`，请求体 `{ testset?, tests: [{ index, source }] }`，返回 `{ testset, removed, manual, lines, renumbered, gaps?, samples?, largeSamples? }`。全部测试点按同一份测试计划解析后才修改：编号不存在为 404，`source` 与调用方所见不一致为 409，模板循环生成的行为 400，任一失败都不删除。`DELETE /api/problems/:id/tests/:n` 使用同一实现。
- 删除后其余测试点前移、保持顺序：编号命名的手写测试（保留补零位数）连同题面样例文件与提供的答案改名，脚本中的显式目标（`> 7`、`> {8-9}`）改写，`> $` 自动前移；脚本测试的题面样例（`tests/_statement/NN.*`）、样例解释（`statement/<lang>/samples/<编号>.tex`）、样例与大样例列表、子任务（逐点求和的子任务减去被删测试点的分值，空子任务删除并由依赖者继承其前置）、逐点设置与初始答案备份的条目都跟随其测试点。改名经隐藏的临时文件进行，不会互相覆盖。
- 模板脚本中由模板生成的显式编号无法改写时，不进行任何前移，返回 `gaps: true`，界面提示编号不连续。
- 仅为跟随测试点的子任务／逐点设置更新（`TestsetPatch.followsTests`）保留导入时未能解析的计分标记；`TestsetPatch.cases` 可整体替换逐点设置。
- 测试面板新增勾选列：表头全选，Shift 点击把从上次点击到本行的测试点加入勾选，Ctrl／⌘ 点击切换；普通点击仍只切换详情区显示的测试点。“删除所选 (N)”在生成测试时禁用；确认框列出手写测试数量、脚本行及其生成的测试点，后面还有测试点时说明它们会前移。

## 导入

- 配置引用、但题包中缺少输入或必需答案的测试点被跳过（Luogu、Hydro、TaskWeave 配套文件、LemonLime、Polygon）。先按配置读入并以占位记录缺失的测试点，再统一移除，因此 Luogu 评分脚本、样例位置与 Hydro 默认分值按原配置计算；未写分值的 Luogu 测试点在实际导入的测试点之间平分 100 分。
- 剩余测试点连续重新编号；子任务、逐点设置、样例、Polygon 脚本行与题面样例随之调整，子任务名称与原文件名不变。整组计分的子任务保留分值，逐点求和的子任务减去被跳过测试点的分值；变空的子任务被删除，依赖它的子任务改为依赖它的前置子任务。
- 每题一条提示 `Skipped N missing tests: …`（列出前 10 个），删除空子任务时另有 `Removed empty subtasks: …`；中文界面显示“已忽略 N 个不存在的测试点：…”“已删除空子任务：…”。两类导入窗口都把它们显示在可折叠的提示列表之外，导入结果与导入说明文件中同样记录；全部测试点都被跳过时导入仍会完成。
- 不变：引用有歧义、答案冲突，以及校验器、grader、Hydro 附加文件、Polygon 资源与校验器自测等非测试数据的缺失，仍拒绝导入；配置未提及且没有答案的 Luogu `.in`、JOI 与普通数据包中缺少答案的输入，仍报告缺少答案。
- 修复：JOI 式 `in/x.txt` + `out/x.txt` 题包缺少 `out/x.txt` 时，路径修复会把它“找到”为 `in/x.txt` 并以“输入与答案是同一文件”拒绝导入。修复引用时不再落到同一测试点的另一个文件上，LemonLime 导入同样处理。

## LemonServer

- LemonServer 0.1.6 删除了比赛时间：替换比赛的提示与使用指南不再说明保留比赛时间。推送时只有服务器返回了起止时间（0.1.5 及更早版本）才把它恢复到新比赛。

## 提示

- 精简界面中较长的提示、确认与说明（中英文各约 30 条），以及十余条服务器导入提示；OI 字体缺失提示的两种情形分别精简。
- 为原先在中文界面中显示英文的导入提示补充中文，包括 Hydro、Polygon 提示与 `Missing file referenced by problem.xml`。
