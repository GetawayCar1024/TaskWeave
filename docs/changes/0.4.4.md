# TaskWeave 0.4.4

2026-11-01 发布，基于 0.4.3。面向用户的说明见 [0.4.4 发布说明](../releases/0.4.4.md)；上一版见 [0.4.3 改动明细](0.4.3.md)。

## LemonServer

- 界面与文档中的“LemonLime Server”统一为“LemonServer”，按钮为“推送到 LemonServer”。
- LemonServer 拒绝凭据时返回 HTTP 400 `lemonserver_auth`，不再返回 401：前端只把 `error: "unauthorized"` 的 401 视为 TaskWeave 自身令牌失效，错误的 API Key 不再跳到“未授权”页面。
- `llk_` / `lsk_` 形式的 API Key 被拒绝时不再当作访问令牌重试登录，提示该 Key 可能已删除或属于另一台服务器，并说明在哪里新建。
- 题面 PDF 版 down.zip 只要求每道题都有同一种语言的题面，纯数据题也可使用；不可用时推送窗口说明原因（没有题目、哪些题缺题面、没有共同语言）。比赛页“导出 down.zip”和打印页同样只在缺题面时退回仅样例。

## 文件命名

- LemonLime 包的数据文件改为“源文件名 + 编号”：`data/trip/trip1.in`、`trip1.ans`；`tests` 以外的测试集为 `trip-<测试集>-1.in`。CDF 路径同步，推送到 LemonServer 的包相同。
- down.zip 的样例答案由 `.out` 改为 `.ans`（`trip/trip1.in`、`trip/trip1.ans`），与 LemonLime 包一致。洛谷 `data.zip` 仍为 `.in` / `.out`（洛谷要求）。导入 LemonLime 包按 CDF 读取文件名，旧包不受影响。

## CNOI 题面

- 整份题面（`statement.tex`）用 `###` 写各节时，最浅一级标题提升为 `##`，与上游模板一致显示为【题目描述】【输入格式】等，不再成为普通文字。
- 表格单元格中的公式含 `|`（如 `$\sum |x| \le 100$`）时不再被拆成多列：公式内 `|` 写为 `\vert`、`\|` 写为 `\Vert`，行内代码内 `|` 转义为 `\|`。

## 测试

- 更新 LemonServer 凭据、LemonLime 数据文件名与 down.zip 文件名的断言；全部 164 项通过。
