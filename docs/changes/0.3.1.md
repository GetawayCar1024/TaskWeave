# TaskWeave 0.3.1 改动明细

基于 0.3.0，发布日期 2026-10-25。面向用户的说明见 [0.3.1 发布说明](../releases/0.3.1.md)，上一版记录见 [0.3.0 改动明细](0.3.0.md)。

## 检查与验证

- 全工作区类型检查、Web 生产构建通过；14 个服务端测试脚本共 71 项通过，覆盖 Polygon 同步（模拟接口）、子任务与导出、跨测试集评测、工作区修复、OI 评测、CNOI 模板与比赛文件。
- 使用临时目录与真实 g++ 完成端到端冒烟测试：建题、多文件生成器、子任务 validator、额外测试集样例、跨测试集评测，导出 LemonLime、洛谷、Polygon 包、TeX 与 down.zip。
- OI 排版用本机宋体、黑体、楷体（含 `simsun.ttc` 字体集合）实际编译中英文、有无目录页四种文档；Electron `printToPDF` 实际生成 PDF，核对纸张、页边距、页码、可选文字与链接。
- 尚未验证：真实 Polygon 账号同步、在洛谷上传导出包、LemonLime GUI 评测，以及界面上的全部交互。

## 许可证与字体

- TaskWeave 采用 AGPL-3.0-or-later，新增 `LICENSE`。
- OI 排版不再内置宋体、黑体、楷体（版权不允许分发），改为从本机字体或全局目录的 `fonts/` 读取，缺少时在预览上方提示；内置的 Fira Mono、Latin Modern、New Computer Modern 附带各自许可证文本。

## Polygon 同步

- 按最新 Polygon API 文档调整：本地删除的解法、源文件、资源、题面（整种语言）、题面资源、validator/checker 自测、手写测试和脚本，推送时在 Polygon 上删除（预览中可逐项勾选）。
- 测试点分值支持最多两位小数；时限不是 50 的倍数或超出 250–15000 ms 时在推送预览中提示建议值；`commitChanges` 无改动时给出提示。
- 只在网络错误、超时、5xx/429 时重试，新建、提交、构建、删除等非幂等操作不重试；取消任务会中断进行中的请求。
- 只修改子任务分值也会被推送。
- 拉取时未处理的冲突与远端改动保留原基线，之后仍显示"Polygon 有改动"，推送前警告；比赛拉取跳过有冲突的题目。
- 能区分"题目已在 Polygon 删除"与"无法访问"。
- 修复拉取样例标记及样例题面输入／输出的若干问题；拉取可获取 tests 以外的测试集（自动探测本地测试集与 pretests，也可手动填写）。
- 比赛同步新增"全部从 Polygon 重新拉取"。
- 子任务单独指定的 validator、OI 专用题面文件（数据范围、样例解释）不会同步，推送预览中提示；拉取不会删除这些文件。
- 拉取写入的所有路径都经过安全校验；重新创建 Polygon 题目时清空旧的合并基线。

## 测试、评测与导出

- 所有测试集都可以设置样例与大样例；新设为样例的测试（包括在"添加测试"中勾选样例）默认不在题面中展示。
- 修复 OI 题有样例时导出 down.zip 总是提示"题面或样例已修改"；OI 题 `statement.tex` 为空时，TeX 导出与预览一致地使用分段文件。
- 样例的"题面输入／题面输出"去掉单独的 ✕，再次点击即恢复默认。
- 信息页删除"样例测试"栏，样例在测试面板中管理。
- 每个子任务可以指定单独的 validator。
- 子任务计分、捆绑、依赖复查：按测试点计分的分值精确分配（如 10 分分给 4 个点为 2,2,3,3），依赖按传递关系处理；重命名或删除子任务时同步更新依赖。OI 目录页"测试点是否等分"在分值不等或无法整除时显示"否"。
- 批量评测可以跨测试集选择任意测试点，窗口改为统一样式的弹窗：按测试集／子任务／范围选择，固定表头，每个解法汇总，标出与标签不符的结果。
- 批量评测、对拍、生成测试等任务运行中关闭窗口后可以重新打开并继续查看进度。
- LemonLime 导出可以逐题选择测试集。
- 新增洛谷导出：数据、`config.yml`、计分脚本（处理捆绑与依赖，总时间默认求和、内存默认取最大，均可改为求和／最小／最大）、检查器源码和说明。
- 本地检查对 grader 交互题忽略缺少输入、输出格式，对 I/O 交互题忽略缺少输出格式。
- 汉化了导出、生成测试和比赛批量操作中的报错。
- 修复：多测试生成器取错文件、编译缓存目录不清理、同一源码在是否链接 grader 时反复重编、grader 题快速运行误链接非解法程序、失效测试残留旧答案、LemonLime 超过 100 个测试点时分值为 0、无测试检查只看 tests/manual。

## 题面与文档

- OI 脚注放在所在段落末尾，与 CF 一致；OI 题面可选择是否包含目录页，题解不含目录页。
- 新增 OI 专用段落：数据范围（`statement/<lang>/constraints.tex`，位于说明之前）和样例解释（`statement/<lang>/samples/<编号>.tex`，紧跟对应样例）；除题目描述外，空段落不渲染。
- 注意事项与上方表格之间加大间距；英文段距缩小；表格默认居中。
- 桌面版"导出 → PDF"直接生成 PDF，文字可选、链接可点击。

## 界面与其他

- 统一工具窗口与对话框样式；可调整大小的区域改为拖动边界；各面板记住滚动位置。
- AI 检查栏的输入框与发送按钮始终可见。
- 比赛文件编辑器与题目编辑器共用标签栏与编辑器设置，支持多标签和左右分栏预览。
- 导入比赛的"选择文件夹"改为"新增文件夹"虚线框。
- 删除比赛会删除比赛文件夹，之后可以重新创建或导入同名比赛；有任务或 AI 运行时拒绝删除比赛或题目。
- 设置中可勾选启用内置编程语言（新增 C++23、C11、PyPy 3、Kotlin、Rust、Go 预设）；C++20 的 Polygon 语言 id 更正为 `cpp.gcc13-64-winlibs-g++20`。
- 修复：注册新检查器后原文件被折叠进"其他"分组而像是消失；`problem.toml` 被无谓重写而丢失注释，以及并发读取时可能重复写入 `input`/`output`；桌面版第二个实例仍会启动服务；保存 `problem.toml` 后其他页面不刷新；原始文件响应缺少安全头；AI 用量记录一次写入失败后全部失败；部分 Responses 兼容服务缺少字段时崩溃。
