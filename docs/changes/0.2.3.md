# TaskWeave 0.2.3 修复明细

本批改动基于 0.2.2，随 0.2.3 发布。面向用户的更新摘要见 [发布说明](../releases/0.2.3.md)。

| 问题 | 实现 |
| --- | --- |
| 深浅色切换与设置页不同步 | 全局同步 Monaco 主题，包括配置编辑器和 diff；设置草稿同步主题、语言，避免保存时覆盖新设置。 |
| 多个题面文件预览不同步 | 预览订阅整个工作区的内容版本，立即使用其他已打开文件的未保存内容。 |
| 手动创建目录与新增语言 | 按角色查看时取消通用新建目录入口；题面、题解右键可新增语言。目录视图仍保留新建目录，用于自定义资源等场景。 |
| AI 删除语言目录 | 允许提出目录删除，逐文件审阅；接受后清除空语言目录，禁止删除题目根目录。 |
| 检查、AI 区域大小 | 右侧区域宽度可拖动；本地检查、AI 问题列表可纵向缩放并记忆高度；改动列表保留拖动分隔条。 |
| 空白 diff | 默认显示空白字符并比较首尾空白，提供“忽略空白差异”开关。 |
| Polygon 编译失败无提示 | 推送构建后查询远端包状态，失败或未能确认成功时显示警告，提示检查编译器与 `__int128` 所需架构。 |
| 移动题目 | 题目“更多”菜单可选择新目录；保持题目 ID、比赛引用、AI 和评测历史。跨卷复制校验后完成移动；仅清除依赖旧路径的编译缓存。 |
| Markdown 导出 | 导出当前题面或题解，移除“包含题解”合并选项；清理正文多余空格、空行，保留代码、样例及公式内容。比赛标题、题目标题及时空限制居中，小节按层级排列；比赛导出沿用“目录页”开关，导出与 PDF 一致的题目总览表，题目名称可点击跳转。下划线、上下标、对齐、字号、复杂表格等使用 HTML 保留格式；含图片时打包为 ZIP。重新渲染比对后修正相邻／嵌套粗斜体、中文标点、字面波浪号、公式边界、链接转义、HTML 内代码空行及表格内容丢失；保留图片宽度限制和表格单元格间距。复杂排版需要阅读器支持 HTML、公式及 MathML，字体、间距与分页由阅读器决定。 |
| 改号后警告错位 | 比赛结果及展开状态以题目 ID 关联，跟随题目移动、改号。 |
| 代码围栏自动修复 | 完整 Markdown 代码围栏可转换为 verbatim，保留代码和空行；不完整围栏只提示。题面及 AI 代码块增加高亮。 |
| PDF 长公式 | 在安全的顶层运算符处自动折行，必要时有限缩小；无法适配的公式显示提示，保留原公式用于导出。 |
| 关闭程序 | 逐个询问未保存文件是否保存、放弃或取消；发现运行中的 AI 后，可取消退出或停止 AI 后关闭。 |
| DevTools | 正式版禁用 DevTools，F12 与 Ctrl+Shift+I 不再打开；开发环境保留调试能力。 |
| Stopped 内容丢失 | 停止流式响应后保存已收到的正文和思考内容；保留已完成工具结果，补全中断结果以便继续会话。 |
| 中文排版 | 调整段落间距、行高和独立公式间距，预览和 PDF 共用样式。 |
| 切换文件位置丢失 | 按文件保留光标、选择区及滚动位置，恢复时避免预览同步滚动覆盖。 |
| 常驻 AI 入口 | 题目右栏按“信息、测试、运行、自测、AI”并列排列，切换时保持宽度和草稿；仅题目页移除顶栏 AI 按钮和面板内重复的标题、关闭按钮。比赛页保留顶栏 AI 按钮、侧栏展开收起及“AI、检查结果”页签，打开比赛时默认收起侧栏。 |
| 批量评测进度与性能 | 编译前保存测试表格，逐步更新结果；限制同时创建的运行任务，默认串行模式让编译和执行共享资源限额。Windows 使用进程 CPU 时间，另记录墙钟时间。 |
| 比赛编号编辑 | 列表题号只读；在“修改题号”窗口编辑，允许临时重复，点击保存时统一检查格式和唯一性。 |
| Polygon 导入比赛缺题 | 任一题失败时不创建残缺比赛，展示失败题目和原因；成功题目保留供重试复用。支持仅在比赛接口可见的题目，并处理目录重名。 |
| 导入题目存储目录 | 导入比赛时可选择已有根目录或浏览新目录；新目录会注册，重试只复用选定目录中的已绑定题目。 |

验证包括全部工作区类型检查、前端与 Windows 发行包构建、24 项服务端回归，以及隔离数据目录下的浏览器和 Electron 流程验证。Markdown 导出通过 25 组重新渲染内容比对，并检查单题、比赛题面及题解的实际下载。发布前补充修复右侧标签切换时组件被重新创建导致 AI 草稿丢失的问题，验证在信息、测试、运行、自测间切换均保留草稿。新增回归脚本：`packages/server/scripts/test-october-fixes.ts`。

边界：Polygon 导入、构建失败使用模拟接口验证，尚未连接真实账号实测。复杂矩阵、嵌套环境等公式不能保证自动折行，必要时需手工使用 aligned 等结构。Windows CPU 时间受操作系统计时粒度影响，短程序可能显示 0 ms；并行评测及其他系统负载仍可能影响耗时，不保证与 Polygon 相同。移动时需先保存文件并结束运行任务；跨卷旧文件若被外部程序锁定，会保留隐藏备份并记录日志。
