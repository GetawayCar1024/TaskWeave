# 0.3.3 改动明细

## 任务生命周期

`jobFollower.ts` 为每个比赛页面统一跟踪任务，合并首次恢复与主动操作的相同任务，终态只处理一次。页面卸载时停止订阅和轮询；提交锁在 HTTP 请求开始前建立。浏览器复现由“1 个任务、2 次提示、2 次下载”修复为三者均为 1。

## 工作区身份和回收站

- `PatchProblemRequest.name` 修改展示／导出短名称并触发比赛刷新；目录、内部 ID、样例来源和历史文件不迁移。
- `TrashStore` 保存独立元数据和完整内容，支持题目、比赛及旧版题目条目。跨盘移动先完成副本再移除源目录；完整副本不会因源清理失败被丢弃。
- 恢复检查目标与身份冲突。新建同名题目时保留回收站中的身份，避免比赛引用被复用。
- 批量永久删除先验证所选条目，回收站页面可恢复、永久删除与清空。

## 校验与题包

- ZIP 校验增加输入类型、目录边界、本地／中央文件头一致性、流式数据描述符及重叠条目检查；保留 CRC、路径、链接、文件数和展开体积检查。
- 导入预览和实际导入共用数据／配置解析，完整 Hydro 包检查题面与程序引用。未通过检查不能提交；导入成功不再自动跳转。
- `buildProblemDataPackage` 是单题、比赛的共同导出入口。洛谷选项保存在 `[exports.luogu]`，比赛请求按稳定题目 ID 传递逐题选项。
- Hydro 导出使用显式测试点、min / sum 子任务与拓扑排序后的依赖；题面转换为 Markdown，保留数学源和复杂 HTML 表格，生成原生样例围栏。
- 本地程序引用随源码整理，公开附件与私有额外文件分别进入 Hydro 的原生目录。

## 验证

新增 `test-release-management.ts` 覆盖任务去重、短名与比赛引用、回收站恢复／冲突／旧版兼容、ZIP 校验及流式描述符、Hydro 导入导出往返和逐题洛谷选项。已有回归覆盖继续运行。

浏览器实测覆盖无效 ZIP 禁止导入、导入后停留首页、纯数据提示关闭与重新显示、短名编辑、逐题洛谷设置、单题 Hydro 下载和回收站操作。发行包通过重新构建、内置版本检查及实际启动验证。
