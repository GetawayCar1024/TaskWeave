# 0.4.0 改动明细

## 数据模型与持久化

- `problem.data_only` 区分完整造题和纯数据模式；默认仍为完整造题，兼容旧题目。
- 测试集的 `answers = "provided"` 使用已有答案；`.out` / `.ans` 保留在题目目录，`.polyforge` 仅缓存可重建副本。
- 测试集 `cases.<编号>` 保存导入的逐点分数、时限（ms）、内存（MiB）和预测试标记；评测与导出使用逐点限制。
- 导入先解析、检查并写入新数据目录，最后替换配置；导入现有题目会备份 `problem.toml`，保留原数据，并检查并发编辑冲突。
- 原包中没有被用作测试输入／答案的文件以原始字节保存在 `other/`，包括源配置与导入说明。

## 导入与导出

- 新增 ZIP 中央目录读取：支持 store / deflate、data descriptor、Unicode Path 扩展；检查校验和、展开大小、重复路径、目录冲突和非法相对路径。
- 洛谷按官方文件名映射 YAML 恢复测试点配置；导出改为平铺的单题 `data.zip` 和比赛中的嵌套单题包。计分脚本名称为 `score.txt`。
- 通过识别导出器使用的计分脚本子集恢复捆绑、按点累加和依赖；YAML 注释保留分组名称和样例索引。任意脚本不会作为代码执行。
- Hydro 区分整题和仅数据导入，支持显式 cases / subtasks、min / sum、依赖 ID、继承限制、自动发现成对数据和旧版 config.ini。
- Hydro 整题支持旧版多语言文件名和显式 statements 清单，附件与原始元数据保留；样例单独存放，避免误算为正式测试分数。
- 独立题面文档复用比赛文档渲染器，不创建临时比赛；单题支持所有已有导出入口，LemonLime 除外。
- 纯数据题目的下发包无需题面 PDF；LemonLime 默认 `comparisonMode: 1`，也可显式配置独立 Lemon checker。

## 题面与比赛文件

- `workspace/statements.ts` 统一读取整体／分段题面，转换写入成功后再移除旧表示。
- 整体题面映射到 Polygon legend；同步预览只展示转换警告，实际同步时更新本地文件。
- 章节合并保留正文和标题，题解、OI 专用内容保持独立；冲突的外部编辑不被覆盖。
- `notes.<lang>.tex` 优先于通用 `notes.tex`，显式空文件抑制回退；CF / OI、快照和 down.zip 使用一致语言。
- OI 依赖读取兼容浏览器已自动解压的 gzip 响应。

## 验证

- 全工作区 TypeScript / Vue 类型检查、生产前端构建。
- 原有回归覆盖 Polygon 模拟接口、grader 与真实本地评测、子任务、工作区、比赛文件和 OI 内容适配。
- 新增 `test-authoring-modes.ts`、`test-data-packages.ts`；扩展 Polygon 同步测试，覆盖实际整体题面推送／拉取。
- Windows 浏览器实测：导入按钮前置条件、比赛文件深浅主题、ZIP 文件导入、纯数据样例设置、单题 data.zip / TeX 下载、题面转换确认及单题 OI 页面渲染。
- 造题执行测试使用 MinGW-w64；独立 Windows 测试程序采用与默认编译配置相同的静态链接，避免依赖额外运行库 DLL。
