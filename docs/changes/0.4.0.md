# TaskWeave 0.4.0 实现与验证

正式名称为 TaskWeave，采用用户确认的原 D 边角精修与 Porcelain 配色。

## 正式更名与升级兼容

- 窗口、首页、favicon、安装程序、快捷方式、导出说明与发行附件使用 TaskWeave；所有工作区版本号为 0.4.0。
- `assets/branding/taskweave.svg` 为正式矢量母版；`pnpm icons` 使用已安装的 Electron 生成 512px PNG、16–256px ICO 和浏览器图标。
- 新安装使用 `~/.taskweave`，新配置尚未建立时接续旧版配置。新增 `TASKWEAVE_HOME/ROOT/TOKEN`，提供升级兼容。
- 保留安装身份、旧版浏览器偏好与数据格式标识；独立 HOME 使用独立桌面配置，便于隔离运行与验证。

## 兼容模式输出管理

- 支持从已登记 solution 重造已有输入的输出；无需先补齐题面、validator 或普通 checker。
- 导入阶段通过 `snapshotImportedAnswers` 记录每个数据集唯一的初始输出版本。旧项目首次使用时记录现有版本，来源明确标为 `existing`。
- 全部输入运行成功、配置与数据仍一致后才发布。发布有临时回滚副本和事务日志，正常结束清理临时数据；初始备份独立保留。
- 支持恢复原始字节，包括空文件、CRLF 与二进制内容；清理普通缓存不删除初始备份。
- “刷新数据”更名为“重新扫描数据”，与“输出管理”操作分别呈现。

## 删除性能

- 回收站版本 2 将大目录保留在原根目录的隐藏 `.taskweave-trash` 下，跨盘只需写入全局索引，不再复制整份题目。
- 支持旧版全局回收内容和 legacy 目录的恢复；新内容的恢复与永久删除均定位到原盘。
- 恢复流程不统计全目录大小；回收站大小首次读取后缓存。
- `bench-recycle.ts --watch --assert-fast`：512 个文件、64 MiB、C/E 跨盘目录的 DELETE 从约 878 ms 降到 35 ms，整目录复制次数由 1 降为 0。

## LemonLime

- 新增六个 Lemon 协议模板：整数、词、按行词、逐行文本、浮点误差、YES/NO。源自 Testlib for Lemons 的 MIT 代码，修改初始化与头文件路径，保留许可。
- `lemon:*` 引用使用独立的共享源码。可在信息页选择，也可从树中复制到本题后修改。
- 导出可选择 Windows/Linux，CDF 使用 `.exe`／无后缀的对应路径。
- 根目录包含两个 g++ 编译脚本；保留源码相对 include 关系，并附完整 Testlib for Lemons。脚本支持目录空格，Windows 使用原生反斜杠与 UTF-8，Linux 使用 Bash 引号与失败退出。
- 同目标平台保留预编译与协议实测；跨平台提供源码，避免将宿主可执行文件错误标为目标程序。

参考：
- [Testlib for Lemons checker sources](https://github.com/GitPinkRabbit/Testlib-for-Lemons/tree/ce95947b3894572e6664c8906bf8768d26c7a77e/checkers)
- [LemonLime casejudger](https://github.com/Project-LemonLime/Project_LemonLime/blob/master/src/core/casejudger.cpp)：`QProcess::start(Settings::dataPath() + task->getSpecialJudge(), arguments)` 使用 CDF 指定路径。

## 子任务顺序

- 保存当前顺序，删除按字典序重排的逻辑。
- 仅允许依赖前面的任务；禁止自依赖。
- `pruneForwardDependencies` 在拖动后按边检查。例如将 b 从 a 后方移到 a 前方，仅删除 `b → a`，保留合法的 `b → c`、`a → c`。

## 短名称与文件夹同步

- 信息页保存短名称时，在原根目录内同步重命名题目文件夹；主页卡片、列表和工作区显示最新短名称。
- 使用持久身份维持比赛引用；题目文件、同步／AI 历史和初始输出备份随目录移动。
- 移动前检查目标目录冲突与完整配置，移动失败恢复原配置。移动期间暂停目录监听，完成后恢复并更新工作区位置。
- 打开的 `problem.toml` 在重命名后刷新；有未保存内容时保留编辑缓冲并显示磁盘变化。
- TeX 下载和含图片 ZIP 内的 TeX 文件也使用最新短名称。
