# TaskWeave 0.4.2-dev

0.4.1 已于 2026-10-28 发布；随后完成完整命名统一并开始 Linux 原生试制。

## 命名与迁移

- 显示名称统一为 **TaskWeave**，包名统一为 `@taskweave/*`；桌面 IPC、API header、浏览器存储、新题包扩展和工作区状态目录使用 `taskweave`。
- 本地开发仓库迁至 `E:\TaskWeaveDev`，已修复关联 Git 工作树路径。
- 升级迁移旧全局目录与路径引用、题目／比赛身份目录、AI 会话、初始答案备份和原盘回收站；更新旧 `.gitignore` 状态规则，同时保留用户其他规则与换行。
- 旧格式入口集中在升级读取器和旧名常量中，新导出全部使用统一命名。
- 新 Windows 应用标识为 `dev.taskweave.desktop`，显式保留既有安装／卸载 GUID 以延续升级关系。

## 导入与管理

- LemonLime 改为在比赛页整场导入：一次创建比赛和全部题目，可逐题取消、改短名称与标题。全部检查通过后才写入，失败时删除本次创建的题目与比赛；题目只保留自己的数据，CDF、选手提交和未导入题目的数据保存在比赛文件中。题目页不再导入 CDF，并提示改用比赛页。
- 批量导入时每道题独立识别格式：同一 ZIP 或文件夹中的 Polygon、Hydro、FPS、数据包和 JOI 题目分别列出，各题只读取自己目录中的文件，也可逐题改用其他格式。窗口先选择题目，再选择格式。
- 批量导入在写入前统一检查全部题目：短名称、限制、与已有题目或本批其他题目重名、文件夹冲突都会逐题标出；任一问题都会使整批不导入，窗口保留全部设置，点击窗口外不会关闭。
- 题目信息新增“源文件名”，默认使用短名称。OI 题面的目录、可执行文件与源程序名，样例和 down.zip 文件名，以及 LemonLime 的 `sourceFileName`、数据目录与默认输入输出文件名都使用它；LemonLime 导入保留原名称。
- 修复导入等窗口的标签对齐：后出现的字段不再错位、输入后才跳动对齐。
- 精简冗余或已过时的提示，例如短名称改名说明不再声称会更新导出内容。

## Linux

- 新增 Linux C++ supervisor，提供直接 argv、Unicode 文件名、重定向、CPU／墙钟时间／RSS／输出限制、进程树管理和双向交互管道。
- Linux 编译忽略 PE 链接器栈参数；运行时设置相应栈限制。
- 提供 AppImage 与 tar.gz 构建、同提交源码包和 SHA-256 文件。
- CI 启动实际打包应用，完成模板评测、嵌套题库、CDF/FPS 导出与初始答案恢复。
