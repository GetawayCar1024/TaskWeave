# Taskweave / D / Porcelain

## Brief

沿用户选中的 D 折带继续精修，英文名称使用 Taskweave。第一眼是一条折带，再看能发现 T；重点比较正形与负形的辨认强度。配色固定为用户选择的 Porcelain。

## Tokens

- Porcelain light `#FFFFFF`：瓷白顶面。
- Porcelain blue `#E6EBF8`：图标底部与轻量选中态。
- Cobalt `#3F54C3`：正面折带与交互。
- Fold `#8396DF`：背面折带。
- Rim `#D7DFF0`：瓷面轮廓。
- Ink `#273451`：文字，次要说明使用较低对比度的同色系。
- 英文品牌使用 Segoe UI Variable Display / Segoe UI，600 字重，紧凑但不挤压；中文说明使用 Microsoft YaHei。正文 14px，方案名 20px，品牌字样 46px。

## Critique before building

六名称 × 六图标的候选卡片矩阵已不适合收敛阶段。改成单一名称、单一配色的大图检查台与连续比较带，避免重复的圆角卡片、宣传标签和装饰性渐变；渐变只用于用户选中的瓷白图标底。辨认辅助仅在点击后出现，不自动播放动画。将“隐藏 T”落实为图形本身的正负形关系，辅助线必须对应实际路径。

- D1 / Soft crease：最接近原 D，调整横折面宽度和底部回折。
- D2 / Counterfold：在折带中挖出倾斜的 T，观察折带与留白之间的视觉切换。
- D3 / Ribbon T：T 更明确，背面折带让它仍具有折叠结构。

保留第二轮原图、原路径与原 HTML。新草案、下载文件和最终应用资源使用独立路径。

## Visual critique

首版 D2 的白色横梁偏粗，容易读成直接放进三角轮廓的字母。将横梁从 21 单位收至 14、竖笔收至 15，使留白更像折缝，再看才出现 T。移动端比较栏的说明改为独立一行，避免标题末字断行。
