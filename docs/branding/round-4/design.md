# Taskweave / D edge refinement

用户反馈：第三轮的 T 太刻意，原 D 更好。精修集中在边角与接缝，T 只是加分项。

## Geometry review

- 原后侧带底边为 x=108–151，前侧为 x=106–148，右端多出 3 单位、左端有 2 单位的错位。统一到底边 x=106–148。
- 原右侧额外叠放的顶面在 y=105 到达 x=181，而连续外斜边应到 x≈180.08。移除这段重叠轮廓。
- 前后带宽统一为 42，中央三角留白与顶部切口用真实边线交点生成。
- 合并后的轮廓裁切所有折面，避免独立圆角造成接缝漏白；只有外轮廓和留白采用极轻微的光学圆角。

## Critique before building

第三轮把“藏 T”变成了形状设计的主目标，偏离“原 D 边角精修”。本轮采用单一精修稿与原稿的直接对照；细节放大来自实际 SVG 路径，方便判断修改是否足够克制。
