# PolyForge 0.3.1：开源发布与 Polygon 同步改进

发布日期：2026-10-25。

PolyForge 自本版起以 AGPL-3.0-or-later 开源。本版按最新 Polygon API 改进同步，新增洛谷导出、跨测试集批量评测和更多 OI 排版选项，并修复使用中反馈的一批问题。0.3.0 的题目与比赛无需迁移即可继续使用。

## 许可证与字体

- 仓库与源码以 AGPL-3.0-or-later 发布；第三方组件保留各自许可证，见 THIRD_PARTY_NOTICES.md。
- OI 排版所用的宋体、黑体、楷体不允许再分发，不再随安装包提供，改为读取本机字体（Windows 自带）。缺少时预览上方会提示，也可以把字体文件放到全局目录的 `fonts/` 中。

## Polygon 同步

- 本地删除的解法、文件、题面、资源、自测、手写测试和脚本，推送时会在 Polygon 上删除，可在预览中逐项取消。
- 支持两位小数的测试点分值；只修改分值也能推送；时限不符合 Polygon 要求时提示建议值。
- 拉取时未处理的冲突不再被视为已同步；能区分题目已在 Polygon 删除与无法访问。
- 修复样例标记及样例题面输入／输出拉取不到；可以拉取 tests 以外的测试集。
- 比赛同步新增"全部从 Polygon 重新拉取"。
- 网络请求只对可安全重试的操作自动重试，取消任务会立即中断请求。

## 测试、评测与导出

- 所有测试集都能设样例；新设的样例默认不在题面中展示。每个子任务可以指定单独的 validator。
- 批量评测可以跨测试集选择任意测试点，窗口改为统一样式；关闭后可以重新打开继续查看进度，对拍、生成测试同样适用。
- 新增洛谷导出（数据、`config.yml`、处理捆绑与依赖的计分脚本）；LemonLime 导出可逐题选择测试集。
- 子任务分值精确分配，依赖按传递关系处理；OI 目录页的"测试点是否等分"判断更准确。
- 导出与生成测试的报错已汉化。

## 题面与文档

- OI 脚注放在所属段落末尾；OI 题面可选是否包含目录页，题解不含目录页。
- 新增 OI 专用的"数据范围"段落和每个样例的"样例解释"；除题目描述外，空段落不再显示。
- 表格默认居中，英文段距收紧，注意事项与上方表格拉开距离。
- 桌面版"导出 → PDF"直接生成 PDF，文字可选、链接可点击。

## 界面

- 工具窗口和对话框样式统一；可调整大小的区域改为拖动边界；各面板记住滚动位置。
- 比赛文件编辑器与题目编辑器统一，支持多标签与左右分栏预览。
- 设置中可勾选启用内置编程语言，新增 C++23、C11、PyPy 3、Kotlin、Rust、Go 预设；更正 C++20 的 Polygon 语言 id。
- 删除比赛会删除比赛文件夹，之后可重新创建或导入同名比赛。
