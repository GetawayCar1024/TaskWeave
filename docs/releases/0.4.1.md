# TaskWeave 0.4.1

本次更新完善题库管理、外部题包交换与 AI 工作流。

## 导入与评测格式

- **自动识别格式**，支持 ZIP、FPS XML、LemonLime CDF，以及直接选择已解压目录；逐题选择存储文件夹、短名称、标题与默认限制。
- **LemonLime 导入**：读取 JSON CDF 和受支持的旧版二进制 CDF，识别包装目录与多 CDF／多题包；恢复测试、共享／重复测试、子任务分值、时空限制和前置依赖。保留原 CDF、源文件、选手提交及额外数据。
- 核对**配置与实际文件**：唯一可确定的大小写、目录或 `.ans`／`.out` 差异会修正并在导入前显示；缺失答案、含糊匹配和冲突会明确报错。未配置的数据保留为额外文件，空任务 CDF 可按无分值数据导入。
- 自定义 Lemon／Testlib SPJ 保留模式 4／5，并在导出时构建源码；只有二进制时保留文件并提示配置可用检查器。传统题与可表示为单提交源码的链接式 grader 可导入；AnswersOnly、CommunicationExec 等其他运行模型会明确提示。
- **Hydro FPS**：支持多题 XML 与 ZIP 中的 XML、Unicode、CDATA、样例、测试、图片与源程序；显式命名的测试按名称配对。单题及比赛可导出 UTF-8 FPS XML。需要完整子任务、附件或 SPJ 配置时使用普通 Hydro ZIP，FPS 的表示限制会提示。
- **Lemon 原生比较**：逐行、忽略空格、实数比较直接写入 CDF 模式 0／1／3，无需附加 SPJ；本地 C++ 实现对齐原生规则，实数精度可设为 0～18。已有六种 `lemon:*` 源码预设继续使用模式 4。
- 兼容题目导入完成时即扫描已有数据；仅调整子任务分值、依赖或顺序时更新元数据，避免无谓重造数据。

## 工作区与设置

- 首页可创建、进入题目与比赛文件夹，目录直接对应文件系统；创建、导入、移动和回收恢复支持嵌套位置，持久身份及比赛引用随目录保留。
- 统一题目与比赛工作区，取消 CF／OI 类型隔离；CF／OI 继续作为文档排版选项。旧配置保持兼容。
- 比赛题目选择显示真实短名称，修复旧 ID 造成的 `road (road1)` 标签。
- 设置修改自动应用并保存；设置页的配置编辑器在编辑过程中保存，离开设置页再次等待最新改动写入。保存失败时显示原因并保留草稿。

## AI

- 兼容模式可以使用文件与数据整理工具；完整造题所需的编译、运行、生成和评测工具仍由真实工作区权限控制。
- 转为完整造题后继续使用原有 AI 会话。
- 进入工作区即可显示已经运行的 AI；阅读前文时保持滚动位置。
- 接受 AI 修改后主动刷新已打开文件；有未保存内容时先提示，并可保留个人草稿进行比较。
