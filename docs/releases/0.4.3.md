# TaskWeave 0.4.3

本次更新新增比赛一键推送到 LemonServer（网页版 LemonLime），可同时推送选手下发包 down.zip；并改进 Linux 版的启动与 OI 中文排版。

## 推送到 LemonServer

- 在“设置 → LemonLime Server”中填写服务器地址和 API Key（也可以直接填访问令牌），可测试连接并查看服务器版本与系统。
- 比赛页“推送到 LemonLime”按服务器的系统（Windows / Linux）生成 LemonLime 评测包并导入；推送后由服务器用自己的 g++ 编译自定义检查器，跨系统同样可用。
- 可修改服务器上的比赛名、逐题选择测试集。已有同名比赛时须确认替换：可保留原比赛的选手程序（推送后重新评测），比赛起止时间总会保留。
- 可额外推送 down.zip：仅样例，或“OI 题面 PDF + 样例”（在本机按比赛的 OI 排版设置生成题面）。替换比赛且不推送新 down.zip 时保留原有的 down.zip。导出 LemonLime 包不受影响。
- 服务器正在评测或排队评测该比赛时拒绝推送；支持 LemonServer 0.1.2 与 0.1.3 的评测队列。

## Linux

- 启动脚本在 Chromium 沙箱不可用时（Ubuntu 23.10 起的 AppArmor 限制，AppImage 与解压的 tar.gz 都会遇到）自动以 `--no-sandbox` 启动，修复 tar.gz 在新版 Ubuntu 上无法启动的问题；沙箱可用时仍然保留。
- 本机没有宋体、黑体、楷体时，OI 排版自动改用已安装的中文字体（如 Noto CJK），中文不再空白；提示中说明可安装 `fonts-noto-cjk`。
- AppImage 需要 FUSE 2：Ubuntu 上可 `sudo apt install libfuse2t64`，或用 `--appimage-extract-and-run` 直接运行。
