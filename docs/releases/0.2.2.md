# TaskWeave 0.2.2

本次更新以界面打磨和日常使用修复为主。

- 润色深浅主题、顶栏、文件列表、设置页等界面；桌面窗口标题栏和背景随主题同步。
- 比赛列表采用更紧凑的行距，改进题名、限制、完成状态和操作按钮的展示。
- 修复比赛短名称无法修改的问题，保留比赛 ID、题目关联和历史记录。
- 题目和比赛页面的 AI 均改为可调整宽度的右侧栏，与主内容并排显示；不再使用文件标签页或遮罩抽屉，收起侧栏后保留草稿与会话。
- 文件标签在松开鼠标中键时关闭，按下时不再立即关闭。
- 每个源码路径只保留一个 exe 缓存；修改源码或编译选项时替换，编译失败时清理旧 exe，并处理运行与重编译之间的并发冲突。
- 修复深色主题下导出 PDF 的纸张背景问题。

本版界面继续使用 Polygon / Codeforces 题面。实验性的 OI 前端已撤下，后端代码保留供后续打磨；已有相关数据不会删除或自动转换。
