# TaskWeave 0.4.0

正式采用 **TaskWeave** 品牌，搭配精修的 D 折带与 Porcelain 配色。窗口、首页、安装程序、快捷方式和发行附件同步使用新名称与图标。

## 兼容模式与子任务

- 可选择解法重新生成已有输入对应的输出，全部运行成功并核对数据后统一替换。
- 每个测试集保留唯一的初始输出备份，支持精确恢复；导入记录导入时的输出，旧题目首次重造前记录现有输出。
- 重造失败、取消或发布中断时保护原数据；普通缓存清理保留初始输出备份。
- “刷新数据”更名为“重新扫描数据”，扫描已有文件与运行解法分别操作。
- 保存手工拖动的子任务顺序；只允许依赖前面的子任务。拖动后逐条移除失效依赖，其余依赖继续保留。

## LemonLime 导出

- 新增 `lemon:ncmp`、`lemon:wcmp`、`lemon:lcmp`、`lemon:fcmp`、`lemon:rcmp6`、`lemon:yesno` 六种模板，可直接选用或复制到题目后修改。
- 导出时选择 Windows / Linux，CDF 使用对应的 checker 文件名。
- 题包根目录提供 `compile-checkers.cmd` 和 `compile-checkers.sh`，用 g++ 编译全部 checker；附源码、Testlib for Lemons、许可与使用说明。
- 跨系统导出提供目标系统的源码构建包。

## 文件管理与反馈

- 删除题目在原题库盘上移动到回收站，跨盘题库无需复制整份数据。
- 修改短名称同步重命名文件夹；主页小字、工作区、比赛与导出名称一起更新，比赛引用和历史继续关联。
- 已打开的配置文件在重命名后刷新，有未保存内容时保留编辑缓冲。
- 题面／题解 Markdown、HTML、TeX、OI PDF、down.zip 和比赛文件下载显示带文件名的成功提示。
- Polygon、Hydro、洛谷与 JOI / AtCoder 的导入导出、多文件逐题配置和原文件名保留继续提供。

## 升级

- 新安装使用 `%USERPROFILE%\.taskweave`；升级接续旧版配置、题库设置、密钥、模板和回收站索引。
- `TASKWEAVE_HOME` 用于自定义全局目录，并提供旧版升级兼容。
- 题目中的 `.taskweave/` 与题包格式标识沿用兼容格式，旧题目和旧题包可继续使用。
