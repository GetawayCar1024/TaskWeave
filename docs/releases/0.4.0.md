# PolyForge 0.4.0：题面模式、纯数据模式与题包交换

发布日期：2026-10-26。

## 修复与比赛文件

- 未设置题目根目录，或未填写 Polygon API key / secret 时，不能点击 Polygon 题目／比赛导入按钮；提交接口也会检查。
- 比赛文件渲染区跟随全局深浅色主题。
- 注意事项支持 `files/notes.zh.tex`、`notes.en.tex` 等多语言文件，导出和可编辑快照选择对应语言；不存在时兼容原来的 `notes.tex`。空的翻译文件表示该语言不显示注意事项。

## 整体／分段题面

- 新建题目时可选择整体编写，保存为 `statement/<语言>/statement.tex`。
- 编辑器标签栏可双向转换。合并前提示丢失分段信息；转回分段时正文全部放入 `legend.tex`，其他正文段落为空。
- 题解、OI 数据范围与样例解释仍独立保存。预览、CF / OI 文档和 Polygon package 支持整体题面。
- Polygon 同步预览展示警告，执行同步时自动转为分段。

## 纯数据模式

仅需输入、答案和分数配置。支持 `.in/.out`、`.in/.ans`，可以标记样例、配置子任务、导出洛谷包、在比赛中导出 LemonLime，以及导出只含样例文件的 `down.zip`。

**不推荐使用这种方式正式造题**：缺少生成器、校验器和标程会降低数据的可验证性与可复现性。运行、批量评测、对拍、Polygon 同步等功能受限；在信息面板补全题面、validator、checker、标程后启用完整造题。已有答案保存在题目文件夹中，清理缓存不会丢失。

纯数据题目的 LemonLime 默认使用内置逐行比较（忽略多余空格与制表符，包括行内多余空白），不需要 checker 源码；配置了独立 Lemon checker 时使用该检查器。

## 洛谷与 Hydro

- **洛谷导出**：每题一个 `data.zip`，根目录包含数据、官方格式的 `config.yml` 和 `score.txt`；比赛导出为每题一个子目录和对应的 `data.zip`。
- `score.txt` 是整题计分脚本副本，上传后需在洛谷网页粘贴设置；洛谷没有自动安装此文件的文档保证。
- **洛谷导入**：恢复数据、逐点分数与限制、Subtask、预测试标记；PolyForge 导出的脚本可恢复捆绑、依赖和样例设置。
- **Hydro 整题导入**：读取 `problem.yaml`、多语言 Markdown／题面清单、样例、`testdata/`、程序配置与附件；多题 ZIP 可选择其中一道题。
- **Hydro 仅数据导入**：向当前题目的目标测试集导入测试点与 `config.yaml`；不替换题面或程序。
- 原始配置、附件和多余文件保存在“其他文件”中。不能表达为本地子任务的自定义计分脚本／规则会明确提示并保留原件，需要编辑子任务后再评测或导出。

## 单题导出

题目页“更多 → 导出单题”支持 Polygon package、洛谷 `data.zip`、CF PDF / HTML / Markdown / TeX、OI PDF / Markdown，以及 `down.zip`。LemonLime 继续从比赛页导出。

同时修复静态服务器自动解压内置 `.tar.gz` 依赖导致 OI 预览失败的问题。

- `PolyForge-0.4.0-portable.exe`：Windows x64 免安装版。
