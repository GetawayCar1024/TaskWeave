# TaskWeave 0.4.2

本次更新新增 Linux x64 版本，改进本地题包导入与题库管理，并将产品名称统一为 TaskWeave。

## Linux x64

- 提供 **AppImage** 与 **tar.gz**。评测使用 Linux 原生监督程序：参数直接传给程序，按进程树统计 CPU 时间与常驻内存，超限或取消时终止整个进程组。
- 运行需要 GTK 3、NSS、GBM 与 ALSA，本地评测需要 g++。AppImage 依赖系统 FUSE，也可以用 `--appimage-extract` 解压后运行。
- OI 排版所需的宋体、黑体、楷体不随应用分发；在 Linux 上请把 `simsun.ttc`、`simhei.ttf`、`simkai.ttf` 放到 `~/.taskweave/fonts/`。
- 内存按 RSS 统计，与 Windows 的提交内存口径不同；当前不提供文件系统或网络隔离。

## 导入与题库

- **LemonLime 整场导入**：在比赛页“导入本地包”选择含 CDF 与 `data/` 的 ZIP、CDF 或文件夹，比赛与全部题目一起创建，可逐题取消、修改短名称与标题。全部检查通过后才写入，失败时删除本次创建的内容；CDF、选手提交和未导入题目的数据保存在比赛文件中。
- **逐题识别格式**：同一 ZIP 或文件夹中的 Polygon、Hydro、FPS、数据包和 JOI 题目分别识别，各题只读取自己目录中的文件，也可以逐题改用其他格式。窗口中先选择题目，再选择格式。
- **整批检查**：导入前检查全部选中题目的短名称、限制、文件夹冲突与重名，有问题的题目会标出；任一问题都会使整批不导入，窗口保留全部设置。
- **短名称在文件夹内唯一**：不同文件夹可以有同名题目；新建、导入、重命名、移动和从回收站恢复时检查目标文件夹。
- **源文件名**：可在题目信息中单独设置选手的目录、程序与样例文件名，默认使用短名称。OI 题面、down.zip 与 LemonLime 包使用同一名称，LemonLime 导入保留原名称。

## 名称与升级

- 产品名称统一为 **TaskWeave**。升级时自动迁移旧版全局目录、题目与比赛状态、回收站和界面设置；Windows 安装版沿用原有的安装与卸载关系。

## 其他改进

- 修复导入等窗口中后出现的字段错位、输入内容后才跳回对齐的问题。
- 精简冗余或过时的提示，例如短名称改名说明不再声称会更新导出内容。
