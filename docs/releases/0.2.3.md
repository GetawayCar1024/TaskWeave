# TaskWeave 0.2.3

本次更新新增题面 Markdown 导出，改进编辑器、AI、比赛管理和批量评测，并修复 Polygon 比赛导入与构建提示。

## 题面与导出

- 支持导出当前题面或题解的 Markdown，含图片时打包为 ZIP；比赛导出包含居中的比赛标题、题目标题和时空限制，以及可点击跳转的题目总览表，“目录页”开关控制是否包含该表。
- 清理正文多余空格与空行，保留代码、样例和公式内容；使用 HTML 保留下划线、上下标、对齐、字号及复杂表格。修复粗斜体边界、链接转义、公式边界与表格内容丢失，经过重新渲染比对验证。
- 移除预览中的“包含题解”选项，题面和题解分别导出。
- 修改任意题面段落后，其他已打开段落的完整预览同步更新。
- 改善中文段落与公式间距、代码块渲染；自动修复支持完整 Markdown 代码围栏。PDF 导出可在安全运算符处折行长公式，必要时缩小并提示无法适配的公式。

## 编辑器与 AI

- 深浅主题切换即时同步编辑器、diff 和设置配置页；切换文件标签保留光标、选择区和滚动位置。
- diff 默认显示空白字符并比较首尾空白，可切换“忽略空白差异”。
- 题目右栏按“信息、测试、运行、自测、AI”并列排列，修复切换标签时 AI 草稿丢失，移除题目顶栏 AI 按钮。比赛页保留 AI 按钮，进入比赛时默认收起 AI 侧栏；AI 与检查结果区域支持调整大小。
- 题面、题解右键菜单支持新增语言；按角色查看时移除通用新建目录入口，目录视图仍可创建资源目录。AI 可删除某个语言目录，接受改动后清除空目录。
- 停止 AI 后保留已经输出的正文、思考内容及工具结果。
- 关闭程序时依次询问未保存文件的处理方式；仍有 AI 任务运行时，可取消退出或停止 AI 并关闭。正式版禁用 DevTools 快捷键。

## 比赛、Polygon 与评测

- 题目可移动到其他根目录，保留题目 ID、比赛引用与历史记录。
- 比赛题号改为通过“修改题号”窗口统一编辑，编辑过程中允许临时重复，保存时检查唯一性；检查警告随原题移动。
- 从 Polygon 导入比赛可选择题目存储目录；支持仅通过比赛接口可见的题目，处理重名目录。部分题目导入失败时显示具体原因，不创建缺题比赛；重试可复用已成功导入的题目。
- 推送并构建 Polygon 包后检查远端构建状态，失败或无法确认时显示提示，包含 `__int128` 等编译环境差异的排查建议。
- 批量评测在编译前显示测试表格并逐步更新结果，限制同时创建的任务；默认串行模式下编译与执行共享资源限额。Windows 使用进程 CPU 时间计时，并单独记录墙钟时间。

## 下载与说明

- [0.2.3 发行附件](https://github.com/GetawayCar1024/TaskWeave/releases/tag/v0.2.3)：Windows x64 安装版与免安装版。
- `SHA256SUMS.txt`：发行文件 SHA-256 校验值。

运行评测需要 PATH 中有 g++（MinGW-w64）。本版继续提供 Polygon / Codeforces 前端工作流。

复杂 Markdown 排版需要阅读器支持 HTML、公式和 MathML，字体、间距和分页由阅读器决定。复杂矩阵等公式仍可能需要手工换行。短程序的 CPU 时间受 Windows 计时粒度影响，并行运行及系统负载仍可能影响测量结果。Polygon 导入及构建失败使用模拟接口验证，尚未连接真实账号实测。

完整修复记录见 [CHANGES_0.2.3.md](https://github.com/GetawayCar1024/taskweave/blob/v0.2.3/CHANGES_0.2.3.md)。
