# TaskWeave 0.4.7

## 本地 Polygon 整场导入

比赛页的“导入本地包”现在接受 Polygon 比赛 ZIP 或已解压目录。支持 `contest.xml` 引用题目目录、内嵌题目 ZIP，以及没有比赛清单的多个 Polygon 题目目录。保留清单顺序、题号和各题源文件名，可逐题取消或改名。

全部选中题目先验证再写入，名称只在目标题目文件夹内检查重复；导入失败会回滚本次创建的内容。公共附件、原始清单和未选择的题目不会丢失。另修复发布题目最后阶段失败时可能残留半成品目录的问题。

原有 Polygon 在线导入、单题导入、LemonLime 整场导入和 0.4.6 的执行隔离、计分规则保持不变。使用已有设置和数据即可升级，无需迁移。
