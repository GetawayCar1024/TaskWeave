# PolyForge 0.3.4

## 题包与导入导出

- 新增 Polygon ZIP 导入，支持整题、多个题目目录、已有数据包及需要生成数据的 standard 包；保留题面、样例、程序角色、原文件名与额外资源。
- 新增 JOI / AtCoder 的 `in/…txt`、`out/…txt` 导入导出。导出附带 `polyforge.yaml` 保存本地分数、依赖与限制；导入裸数据时无需该文件。
- 导入选项按 Polygon、Hydro、数据包、JOI / AtCoder 排列；导出按 Polygon、Hydro、洛谷、JOI / AtCoder 排列，比赛另提供 LemonLime。
- “洛谷数据包”导入改名为“数据包”，按内容识别洛谷、Hydro 与 PolyForge 配置，支持不同配置文件名及 YAML、JSON、TOML。
- 一次选择多个 ZIP，分别设置每道题的名称、标题、默认限制和目录；导入后停留在首页。
- Hydro 的 `.in` / `.out` 附加文件归入其他文件，图片分类仅显示图片。

## 子任务

- 原有参数表格增加按原文件名搜索、勾选、全选及反选测试点的窗口。
- 同一测试点可属于多个子任务；首个名称默认 `0`。可拖动编辑顺序，保存后按名称字典序排序，依赖只能指向更小的名称。
- 可从 `xxx-yyy` / `xxx_yyy` 文件名建议分组，分数由用户设置；未匹配的文件会提示。
- “捆绑”内每个测试点使用子任务分数，取最小值；“加和”设置每个测试点的统一分数。总分无需为 100。
- 子任务独立设置时间与内存。共享测试点按不同预算分别运行，导出时检查目标格式能否表示这些限制。
- 修复 LemonLime 导出漏读子任务时空限制；新增“从子文件夹寻找选手代码”，默认关闭。

## 交互与性能

- “纯数据模式”改为“兼容模式”，精简提示。
- 自定义输入框失焦后保留草稿，手动保存生效；切换信息页签或离开题目时提示未保存更改。校验输入与输出文件名不同。
- 导出窗口完全关闭后显示成功提示，避免重复下载；快速任务不再额外等待一次轮询周期。
- 未变化的数据刷新跳过全量读取、哈希与副本比较，并合并并发刷新；压缩使用后台线程及快速压缩，已压缩的内层 ZIP 不再重复压缩。
- 桌面资源合并为 ASAR，减少安装、便携版解压时创建的小文件；评测运行器源码单独保留供编译。

## 格式兼容说明

- JOI / AtCoder 没有统一公开的评分配置标准，`polyforge.yaml` 是 PolyForge 的往返配置。
- Polygon XML 每个测试集只能使用一组时空限制。共享测试点在 ZIP 中创建独立归属副本，重新导入时合并；Polygon API 同步仍要求每个测试点只有一个分组。
- Polygon checker-percent 等当前本地模型不能完整表达的规则会保留原配置并提示；standard 包不会在导入时自动执行程序，缺失数据由后续生成操作构建。
- LemonLime 要求整数毫秒、整数 MiB、整数分值；同一捆绑条目不能混用不同限制。Hydro 的默认评测预算由部署配置；洛谷自定义计分仍需粘贴导出的 `score.txt`。
