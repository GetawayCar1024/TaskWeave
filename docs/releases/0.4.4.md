# TaskWeave 0.4.4

本次更新修复推送到 LemonServer 的若干问题，统一下发与评测数据的文件名，并修正 OI（CNOI）题面排版。

## LemonServer

- 名称统一为“LemonServer”，比赛页按钮为“推送到 LemonServer”。
- API Key 错误时不再显示“未授权，请使用终端里打印的链接打开本页面”，而是提示 Key 可能已删除或属于另一台服务器，并说明在 LemonServer 网页中新建的位置。
- 只要每道题都有题面（纯数据题也可以），推送和导出都能选择“OI 题面 PDF + 样例”的 down.zip；不能选择时窗口中会写明原因。

## 文件命名

- LemonLime 包中的数据文件按“源文件名 + 编号”命名，如 `trip1.in`、`trip1.ans`，与 down.zip 中的样例一致。
- down.zip 中的样例答案改为 `.ans`。洛谷 `data.zip` 仍使用洛谷要求的 `.out`。

## OI 题面

- 用 `###` 书写各节的整份题面，现在与原项目一样显示为【题目描述】【输入格式】等小节标题。
- 表格中含 `|` 的公式（如 $\sum |x|$）不再把表格拆乱。

## 下载

- [0.4.4 发行附件](https://github.com/GetawayCar1024/TaskWeave/releases/tag/v0.4.4)：
  - Windows x64：`TaskWeave-0.4.4-setup.exe`（安装版）、`TaskWeave-0.4.4-portable.exe`（免安装版）。
  - Linux x64：`TaskWeave-0.4.4-linux-x86_64.AppImage`、`TaskWeave-0.4.4-linux-x64.tar.gz`。
  - `TaskWeave-0.4.4-source.zip`：对应标签的源码、锁文件和构建资源。
  - `SHA256SUMS.txt`：全部附件的校验值。

升级保留全部设置、题目数据、历史和初始答案备份。
