# TaskWeave 0.4.5

本次更新支持批量删除测试点，删除后其余测试点自动前移；导入题目时，配置中引用、但题包中不存在的测试数据会被跳过并提示，不再使导入失败。

## 删除测试点

- **批量删除**：在“测试”面板勾选多个测试点（表头可全选，Shift 点击选择一段，Ctrl 点击切换），点“删除所选 (N)”后一次确认、一次完成；任一测试点已变化时全部不删除。手写测试删除其文件，脚本测试删除所在的脚本行，同一行生成的测试点一并删除。
- **其余测试点前移**：删除后，后面的测试点依次前移、顺序不变，编号保持连续（原先删除中间的手写测试会留下空号，导致无法生成测试）。编号命名的手写测试改名，脚本中的显式编号（`> 7`、`> {8-9}`）改写，`> $` 自动前移；样例、子任务、逐点设置、样例解释和初始答案备份随之调整，变空的子任务被删除。模板生成的编号无法改写时不前移，并提示编号不连续。单个删除同样如此。

## 导入时缺少的测试数据

- Luogu `config.yml`、Hydro `config.yaml`、TaskWeave 配套文件、LemonLime CDF 与 Polygon `problem.xml` 中引用、但缺少输入或答案文件的测试点会被跳过，其余测试点按原顺序重新编号，子任务、分值与样例随之调整；变为空的子任务被删除，依赖它的子任务改为依赖它的前置子任务。未写分值的 Luogu 测试点在实际导入的测试点之间平分 100 分。
- 导入前的预览中直接显示“已忽略 N 个不存在的测试点：…”与“已删除空子任务：…”，导入结果与导入说明中也会记录。
- 引用有歧义（有多个候选文件）、答案冲突，以及缺少校验器等非测试数据的文件时，仍与之前一样拒绝导入。

## LemonServer

- 适配 LemonServer 0.1.6：它已删除比赛时间，成绩与评测详情任何时候都可查看。替换比赛的提示不再说明保留比赛时间；向 0.1.5 及更早版本推送时，原比赛的起止时间仍会保留。

## 其他改进

- 修复 JOI 式 `in/x.txt`、`out/x.txt` 题包中缺少 `out/x.txt` 时，被误认为与输入是同一文件而拒绝导入的问题。
- 精简界面提示与导入提示；部分原先只显示英文的导入提示补充了中文。
