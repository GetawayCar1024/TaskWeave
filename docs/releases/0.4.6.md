# TaskWeave 0.4.6

本次为执行隔离与部分分兼容性修复。建议升级 0.4.5 及更早版本。

## 执行隔离

- 编译器、解法、生成器、validator、checker、interactor 及 AI 调用的运行均经过隔离。Windows 使用独立 AppContainer 和 Job Object，Linux 使用 bubblewrap、命名空间和 seccomp；不继承宿主凭据环境，不授予网络访问，解法与 interactor 分开工作目录。
- 隔离准备失败时明确报错，不自动改为无隔离运行。AI 与文件接口拒绝符号链接、junction 和硬链接越界；检查程序输出，避免宿主跟随链接访问其他文件。
- Electron 明确保留渲染沙箱，精确校验导航来源，禁止调用任意外部协议；Linux 启动器不再自动添加 `--no-sandbox`。

**升级后的环境要求：** Windows 需要可用的 g++ 和支持 AppContainer 的系统、文件权限；Linux 需要 `g++`、`bubblewrap` 及用户命名空间权限，例如 `sudo apt install g++ bubblewrap`。Chromium 的渲染沙箱也必须可用。不要以管理员／root 身份运行来源不明的程序。

这不是可公开托管不可信用户的在线评测服务，也不提供完整磁盘配额或内核漏洞防护。已重点验证 C++、Python；其他运行时与自定义编译封装可能需要单独适配。详见 [执行隔离与计分边界](https://github.com/GetawayCar1024/TaskWeave/blob/v0.4.6/docs/security.md)，安装包也附带 `SECURITY.md`。

## 部分分与平台兼容

- 修正 `quitp(0.5)` 在 40 分子任务中被算为 0.5 分的问题：按比例应为 20 分。题目信息可以选择比例、绝对分数、百分比或 Hydro Testlib 兼容模式；部分正确显示为 **PC**，不会被当成完全通过前置子任务。
- 正确读取 `_pc` 报告；无法解释的 `quitpi`、非数值或越界分数会报错，不会当作满分。已有历史评测记录不会被重新解释。
- 洛谷包增加每个子任务的计分脚本，保留捆绑组的部分分。**上传后仍须按包内 README 分别设置 `score-subtask-<id>.txt` 和整题 `score.txt`，洛谷不会自动安装这些脚本。**
- Hydro 导入保留其 Testlib 比例／百分比判定与逐点取整规则，导出在支持的语法范围内转换计分协议。
- 不再静默替换本地自定义 checker 为 Lemon 默认比较器；无法等价转换的 Polygon 比例依赖、API 同步或 checker 协议会明确阻止操作。
