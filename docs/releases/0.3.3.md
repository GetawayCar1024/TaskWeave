# PolyForge 0.3.3：回收站、题包校验与逐题导出

发布日期：2026-10-27。

## 发布版本修正

0.3.2 的 Windows 安装版、免安装版、源码 ZIP 与校验文件已重新上传。安装程序、应用可执行文件和源码中的版本均为 0.3.2，修正之前附件名与内置版本不一致的情况。

## 工作区与回收站

- 纯数据模式的顶部提示可点击叉号关闭；每次重新进入题目时再次显示。
- “信息 → 题目信息”新增短名称编辑。比赛列表、题目总览、下发样例目录和题包名称自动使用新短名；内部 ID 与工作目录保持稳定，文件和历史记录继续关联。
- 首页新增“回收站”，支持恢复、永久删除和清空，兼容旧版回收站中的题目。
- 删除题目或比赛时保存完整目录与记录。恢复题目后，引用其原有身份的比赛自动重新关联；恢复不会覆盖已有目录或身份。
- 题目仍在回收站时，新建同名题目会分配不同的内部 ID，避免错误接管旧比赛引用。
- 从 Polygon 或本地题包导入题目后停留在首页，刷新题目列表。

## 导入 ZIP 校验

选择文件后先校验 ZIP 文件头、目录与本地文件头的一致性、数据描述符、CRC、路径及体积限制，再检查测试点配对、配置和程序引用。校验通过后显示文件数、测试点数与解压大小；未通过时不能点击导入。实际写入前服务端再次校验。

## 单题与比赛导出

- 单题新增 **Hydro 整题包**：包含 `problem.yaml`、多语言 Markdown 题面、样例、`testdata/config.yaml`、输入／答案、程序和附件。数学公式保留为 TeX，程序的本地引用随包整理；其他文件保存为私有测试数据。
- Hydro 和洛谷都先生成每道题的独立 ZIP，比赛导出再把它们放入各题目目录中统一压缩。洛谷内包为 `data.zip`，Hydro 内包为 `<短名称>-hydro.zip`。
- 洛谷的用时、内存汇总方式在单题导出时设置，在比赛导出窗口也可逐题设置；选项保存在对应题目的 `problem.toml` 中，支持求和、最小值和最大值。
- 修复首次打开比赛页面时，任务恢复与主动导出同时跟踪同一任务导致的重复成功提示、重复下载；请求返回前不能重复提交，离开页面后旧回调不会再触发下载。导出文件名也增加唯一后缀。

Hydro 的通信管理器与本地链接式 grader 不是同一协议，grader 题需要先适配；I/O 交互题导出会提示核对交互器。Hydro 会重分配某些零分配置，不能保持原分数的配置会明确报错。洛谷 `score.txt` 仍需在网页中单独配置。
